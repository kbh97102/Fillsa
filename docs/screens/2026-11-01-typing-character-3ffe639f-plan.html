원문·AS-IS·기준

  • Notion 원문은 Android/iOS 수정 전 캡처와 캐릭터·안내 문구가 있는 목표 캡처를 제공한다. 페이지 본문에는 iOS와 Android의 과거 분석·수정 기록이 혼재한다. 기존 보존 원문/첨부를 참조한다.
  • 2026-10-29 SooJi 댓글은 캐릭터가 이제 표시된다고 말하며 iOS 안내 Bold와 iOS 복사 버튼 문제를 추가했다. 두 후속 항목은 Android 캐릭터 적용 범위 밖이며 본 이슈의 Android 완료와 Notion 전체 완료를 구분한다.
  • 수정 전 Android 재현은 2026-10-25 원인 분석과 증거에 보관되어 있다. 당시 TypingQuoteView의 TopSection과 BodySection 사이에 안내 컴포넌트가 없었다.
  • Figma: Light 2929:17920, Dark 3087:28815, 모두 360×720. 안내 그룹 Light 3087:28754, Dark 3087:28984; 60×60 캐릭터와 Pretendard Bold 16/24 #5C65FF 문구. 현재 Light와 Dark 전체 기준 이미지는 2026-10-25 추출본과 각각 SHA-256이 동일하다.

해결 설계와 현재 구현

  • 기존 수정은 정적 TypingQuoteGuide가 원본 Handwriting 캐릭터 래스터와 안내 문구를 표시하고, TypingQuoteContent가 TopSection 다음에 이를 배치하며 20dp 아래 BodySection을 놓는 방식이다. 새 UI state/action/effect/API/data/domain 계약은 없다.
  • 현재 구현에서 TypingQuoteGuide.kt의 캐릭터는 typing_handwriting drawable, 문구는 R.string.typing_guide, 색상은 R.color.purple01이며 Bold 16/24 테마 서체를 사용한다. TypingQuoteView.kt에 조립되어 있다.
  • 기존 해결 대안인 BodySection 내부 직접 삽입 대신 독립 안내 컴포넌트를 유지한다. Light/Dark 자산이 동일함은 기존 QA에서 검증됐다. 이번 재검증은 변경 필요성을 발견하지 않는 한 코드 수정 없이 결과를 보고한다.
