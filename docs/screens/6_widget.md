# 홈 화면 위젯

## Android 구성

- Glance 위젯: `app/src/main/java/com/arakene/fillsa/widget/ui/AppWidget.kt`
- 구성 화면과 선택 미리보기: `MyWidgetConfigScreen.kt`, `WidgetPreview2x2.kt`, `WidgetPreview4x2.kt`
- 범위: 2×2·4×2 위젯, 최소/최대 크기, 긴 글, 연속 필사 알림, 구성 화면 선택 표시, 위젯 탭으로 앱 진입

## Figma UI 기준

- Figma URL: [위젯 디자인 섹션](https://www.figma.com/design/VdFocqyqTgevMVCQxwAQ2X?node-id=2355-2140)
- 대상 프레임/노드: 일반 문구 2×2 `2416:2839`(109 × 115px), `2354:1832`(306 × 276px); 긴 문구 `2416:2994`, `2416:3021`; 일반 문구 4×2 `2354:1825`(245 × 115px), `2398:2250`(624 × 276px); 긴 문구 `2398:2114`, `2355:1900`; 연속 필사 알림 `2396:1717`, `2396:1689`, `2396:1747`, `2396:1795`. 섹션 하위 `2398:2828`은 위젯 크기 표로, 구성 화면의 선택 테두리 디자인이 아니다. 구성 화면의 독립 프레임은 추가 확인이 필요하다.
- 대상 기기/프레임 크기: 위 크기는 위젯 개별 Figma px. 실제 런처·밀도·API 레벨은 운영 검증 시 기록. 언어는 한국어, 밝은 위젯 상태.
- 검증 상태: 위젯 개별 기준 이미지 확보, Android/운영 미검증
- 기준 이미지: [위젯별 PNG 폴더](../design-qa/artifacts/2026-10-04-widget-figma/)의 `figma-<노드 ID>.png` (위 노드 12개 각각 저장), [크기 표](../design-qa/artifacts/2026-10-04-widget-figma/figma-2398-2828.png)
- QA 기록: [위젯 운영 QA](../design-qa/2026-10-04-widget-production-qa.md)

Figma 섹션은 여러 위젯 변형을 모은 캔버스이며, 개별 위젯 프레임과 운영 런처 전체 프레임은 검증 단위가 다르다. 위젯 탭의 앱 진입 동작은 정적 Figma 이미지로 판정할 수 없어 실제 운영 빌드에서 확인한다.
